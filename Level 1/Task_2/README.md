# Number Guessing Game

## Codveda Technologies Java Development Internship

This project is developed as part of the Codveda Java Development Internship.

## Project Description

A console-based Number Guessing Game developed using Java. The program generates a random number between 1 and 100, and the user tries to guess the correct number.

## Features

> Generate random number using Java Random class
> User input using Scanner class
> Feedback system:
  -Too High
  -Too Low
  -Correct
> Maximum attempt limit
> Invaild input handling
> Game over message

## Technologies Used

> Java
> Scanner Class
> Random Class

## How to run

> Open the project in VS Code or any Java IDE.

> Open 'NumberGuessingGame.java'.

> Compile and run the program.

javac NumberGuessingGame.java

> Run the program:

java NumberGuessingGame

> Enter a number between 1 and 100 and try to guess the correct answer.
