# Factorial Calculation using Recursion

## Codveda Technologies Java Development Internship

This project is developed as part of the Codveda Java Development Internship.

## Task Description

This program calculates the factorial of a given number using recursion in Java.

## Features

- Uses recursion to calculate factorial.
- Handles base cases:
  - 0! = 1
  - 1! = 1

## Technologies Used

- Java
- Recursion
- Scanner Class

## How to Run

Compile:

Compile:

```bash
javac Factorial_Calculation.java
```

Run:

```bash
java Factorial_Calculation
```
